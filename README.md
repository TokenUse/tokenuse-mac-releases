# TokenUse for Mac — releases

Signed builds and the update feed for the **direct edition** of
[TokenUse for Mac](https://www.tokenuse.ai), the menu bar companion to the TokenUse CLI
and dashboard. Installed copies update themselves from here.

- Feed: `https://github.com/TokenUse/tokenuse-mac-releases/releases/latest/download/appcast.xml`
- Every archive and the feed are signed with TokenUse's EdDSA key and verified by the app
  before anything is installed.

The app's source is private; this repository only hosts release artifacts.
Questions: support@tokenuse.ai
